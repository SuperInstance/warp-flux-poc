# warp-flux-poc

**FLUX execution proof-of-concept** — demonstrates the FLUX constraint compilation pipeline from specification to execution.

## What This Gives You

- **FLUX pipeline demo** — end-to-end from constraint spec to compiled execution
- **Proof of concept** — validates the COLLECT→SELECT→COMPILE pipeline
- **Benchmark results** — performance data for the FLUX execution model

## How It Fits

Validation prototype for the `flux-lang` and `flux-vm-v3` ecosystem. The results here justified building the full FLUX compilation pipeline.
